# 분석 에이전트 blind 시험

`python eval_agent_blind.py 3 --seed 30 --modes v2 --kinds stuck,v_offset,speed_0,bms_half --length 50 --tag r3short` · 세션 3개에 규칙에 없는 이상 4종(각 50행)을 숨기고, 지시문 1가지로 각 3번 실행.

- hint: 지시문 3번에 '신호가 같은 값에 멈춘 구간이나 신호끼리 서로 모순되는 구간처럼' 이 있음 (이전 eval_agent.py 와 같음)
- blind: 그 구절을 뺌 ('지표에 안 잡히는 이상이 있는지 직접 찾아라' 만)
- v2: blind + column_profile 도구(열마다 요약) + '모든 열을 확인하고, 하나 찾았다고 멈추지 말 것' (이상 종류는 알려 주지 않음)
