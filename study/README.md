# SQL 연습 문제 (내 주행 데이터로)

`telemetry.db`를 대상으로 쉬운 것부터 어려운 것까지 12문제. 위 프로젝트 쿼리를 읽기 전에 먼저 풀어 본다.

**푸는 법:** `my_answers.sql`에 `-- Q1`, `-- Q2` … 머리줄 아래 쿼리를 쓰고 `python check.py`를 실행하면
정답 쿼리(`answers.sql`)와 결과가 같은지 문제마다 알려 준다. 정답 파일은 다 풀고 나서 연다.

| # | 단계 | 문제 | 배우는 것 |
|--|--|--|--|
| 1 | 기초 | 세션별 행 수를 라벨과 함께 보여라 | `SELECT`, `FROM` |
| 2 | 기초 | 차량 속도가 60 km/h를 넘은 행은 몇 개인가 | `WHERE`, `COUNT` |
| 3 | 집계 | 세션별 최고 속도와 평균 팩 전압(소수 1자리) | `GROUP BY`, `MAX`, `AVG`, `ROUND` |
| 4 | 집계 | 인버터 전류가 25 A를 넘는 행이 1,000개 이상인 세션만 | `HAVING` |
| 5 | 조인 | 4번 결과에 세션 라벨을 붙여라 | `JOIN ... USING` |
| 6 | 조인 | `bms_current`에 `scale_correction`의 계수를 곱한 값의 세션별 평균(부하 구간) | 조인으로 표의 값 쓰기 |
| 7 | 서브쿼리 | 전체 평균 속도보다 빠른 행이 세션별로 몇 개인가 | 스칼라 서브쿼리 |
| 8 | CTE | 부하 구간만 `WITH`로 먼저 뽑고, 거기서 세션별 비율(팩/인버터) 평균 | `WITH` |
| 9 | 창 함수 | 각 행의 바로 앞 행과의 `stm_ms` 간격을 구하고, 간격별 개수 상위 5개 | `LAG`, `OVER (PARTITION BY ... ORDER BY ...)` |
| 10 | 창 함수 | 세션별 비율 중앙값 (MEDIAN 함수 없이) | `ROW_NUMBER`, `COUNT() OVER` |
| 11 | 응용 | 인버터 전류가 25 A를 넘는 '연속 구간'은 세션별로 몇 개이고, 가장 긴 구간은 몇 행인가 | gaps-and-islands |
| 12 | 응용 | 부하 구간에서 팩 = a·인버터 + b 의 기울기 a를 집계 함수만으로 | 최소제곱식을 SQL로 |

3번에서 말이 안 되는 최고 속도가 나오면 왜 그런지 `sql/01_flags.sql`과 비교해 본다.

각 문제 정답의 결과 행 순서는 `session_id` 오름차순이다 (2, 9번 제외).
